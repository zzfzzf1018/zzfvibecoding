# 使用手册

## 1. 启动与首次运行

首次启动时程序会：

1. 在 `%LOCALAPPDATA%\StockAnalyzer\` 下创建 `stock.db`；
2. 加载自选股并批量刷新其行情；
3. 在**后台**尝试同步全市场股票列表（用于离线检索加速）。

第 3 步失败不影响任何功能——检索会自动走在线接口。状态栏会显示当前进度。

> 想做成绿色便携版？把 `appsettings.json` 里的 `Storage:DatabasePath` 改成
> `"data/stock.db"`，数据库就会落在程序目录下。

---

## 2. 检索股票

在顶部搜索框输入即可，支持三种方式：

| 输入方式 | 示例 | 说明 |
|---------|------|------|
| 证券代码 | `600519`、`00700`、`000001` | 支持部分匹配 |
| 中文名称 | `茅台`、`腾讯`、`银行` | 支持部分匹配 |
| 拼音首字母 | `gzmt`、`txkg`、`payh` | 大小写不敏感 |

右侧「市场筛选」下拉可限定 **全部 / A 股 / 港股**。

结果列表按相关性排序：代码全等 → 代码前缀 → 名称全等 → 名称前缀 → 拼音首字母 → 名称包含。

**单击**结果即开始加载该股的完整分析；**双击**结果直接加入自选。

---

## 3. 自选股

- 加入自选：搜索结果**双击**，或在详情页头部点击「**加入自选**」。
- 查看自选：左侧切到「**我的自选**」页签，列表显示最新价、涨跌幅、PE、PB。
- 刷新行情：顶部「**刷新自选行情**」按钮（批量请求，一次拿完）。
- 移除自选：选中后点击列表下方「**移除选中自选**」，会有二次确认。

自选股保存在本地数据库，重装/重启不丢失。

---

## 4. 基本信息

选中个股后，右侧头部展示名称、代码、市场、最新价与涨跌（**红涨绿跌**）。
「基本信息」页签以卡片形式展示：

| 分组 | 指标 |
|------|------|
| 价格 | 最新价、涨跌幅、今开、昨收、最高、最低、振幅 |
| 交易 | 换手率、成交额 |
| 规模 | 总市值、流通市值、总股本 |
| 估值 | 市盈率 TTM / 静态 / 动态、市净率 PB、每股净资产 |

三个 PE 的区别（鼠标悬停也有提示）：

- **TTM**：滚动最近 12 个月净利润 —— **本软件的分位数与估值通道都基于这个口径**；
- **静态**：基于最近一期年报，更新最慢；
- **动态**：把最新报告期业绩年化推算，最激进。

港股的金额单位为**港元**，A 股为**元**。

---

## 5. 历史分位

页签内包含两张表（PE 与 PB）和一张走势图。

表格每一行是一个回溯窗口（近 1 / 3 / 5 / 10 年），列含义：

| 列 | 含义 |
|----|------|
| 当前 | 当前估值倍数 |
| 分位 | 当前值在窗口内的百分位，颜色随高低变化（绿低 / 黄中 / 红高） |
| 评价 | 极度低估 / 低估 / 合理 / 高估 / 极度高估 |
| 最小、30%、中位、70%、最大 | 窗口内的分位点数值 |
| 样本 | 参与统计的有效交易日数 |

下方走势图可切换**指标**（PE / PB）与**窗口**，图中虚线为
10%、30%、50%、70%、90% 分位水平线。**切换不产生网络请求，全部本地计算。**

### 怎么读

- 分位数只回答「相对自己的历史，现在算贵还是便宜」；
- 样本列显示「数据不足」时（次新股），长窗口结论不可靠；
- 亏损期的负 PE 已被剔除，周期股底部 PE 分位常常失真，**建议同时看 PB**；
- 如果详情页提示「近似模式」，说明未取到财报，此时曲线形状等同于股价，仅供参考。

---

## 6. 估值通道

把估值倍数的分位数换算回**价格**，因此可以直接和股价对照。

- 白色粗线：实际收盘价（不复权）；
- 绿 → 黄 → 红五条细线：10%、30%、50%、70%、90% 分位对应的价格；
- 图例中括号内的数字是该分位对应的估值倍数；
- 可切换 **PE / PB** 口径与 **1/3/5/10 年** 窗口。

解读要点：

| 现象 | 含义 |
|------|------|
| 股价贴近下沿 | 估值处于历史低分位 |
| 股价贴近上沿 | 估值处于历史高分位 |
| 通道整体上移 | 每股盈利/净资产在增长，是业绩驱动 |
| 通道整体下移 | 盈利在下滑，股价不动估值也会被动抬升 |
| 通道忽然跳变 | 财报切换点，属于正常现象 |

图表支持鼠标滚轮缩放、拖拽平移、右键菜单（保存图片等）。

---

## 7. 数据管理

状态栏右侧实时显示本地数据统计（股票列表 / 自选股 / 行情快照 / 日线记录 / 财报记录）。

| 操作 | 作用 |
|------|------|
| **同步股票列表** | 强制重拉全市场代码。该接口限流较严，失败属正常，不影响检索 |
| **刷新自选行情** | 批量刷新自选股的最新报价 |
| **清理缓存** | 删除本地日线与财报（**保留自选股与股票列表**），并执行 VACUUM 压缩数据库 |
| 详情页「强制刷新」 | 忽略缓存，重新拉取该股的行情、日线与财报 |

缓存有效期：行情 1 分钟、日线 6 小时、财报 7 天、股票列表 3 天。
正常使用无需手动清理，只有在怀疑数据错误时才需要「强制刷新」或「清理缓存」。

## 8. 常见问题

**Q：搜不到某只股票？**
先确认市场筛选没有限制错；再点「同步股票列表」。即便列表同步失败，
在线检索通常也能找到——若仍搜不到，可能是该标的不在 A 股 / 港股范围内
（本软件会过滤掉指数、板块、美股、基金等）。

**Q：分位数和东财 App 有出入？**
各平台在这些细节上口径不同：TTM 的还原方式、是否剔除亏损区间、
分位数是否插值、窗口端点如何取。数量级一致即属正常。

**Q：为什么某只港股显示「近似模式」？**
说明未取到该股的财务指标。冷门港股、次新股较常见，此时估值曲线仅反映价格形状。

**Q：断网还能用吗？**
可以。已缓存过的股票仍可查看基本信息、分位数与估值通道；
检索也能在本地已有数据中进行。只是无法获取最新报价。

**Q：数据库在哪？可以备份吗？**
默认在 `%LOCALAPPDATA%\StockAnalyzer\stock.db`。直接复制该文件即可备份
（建议关闭程序后再复制，同时带上 `-wal` / `-shm` 文件）。
