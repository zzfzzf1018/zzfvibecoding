# 估值算法说明

本文说明 PE / PB 历史序列、分位数与估值通道的完整计算口径，以及已知的局限性。
对应代码位于 `src/StockAnalyzer.Core/Analytics/`。

---

## 1. 总体流程

```
不复权日线 ─┐
            ├─► ValuationSeriesBuilder ─► 逐日 ValuationPoint(date, close, epsTtm, bps, pe, pb)
定期报告   ─┘                                   │
                                                ├─► ValuationAnalyzer.CalculatePercentile → 分位数
实时快照   ─────────► 口径校准 ─────────────────┘
                                                └─► ValuationAnalyzer.BuildChannel      → 估值通道
```

---

## 2. 逐日估值序列

### 2.1 为什么用不复权价

估值倍数是「价格 ÷ 每股指标」。财报中的每股收益、每股净资产都是**基于当期股本**计算的，
因此必须与**当期实际成交价（不复权）**配对，才不会因送转股造成系统性偏差。

$$PE_{TTM}(t) = \frac{P_{\text{不复权}}(t)}{EPS_{TTM}(t)} \qquad PB(t) = \frac{P_{\text{不复权}}(t)}{BPS(t)}$$

### 2.2 TTM 还原

A 股财报披露的是**年初至报告期的累计**每股收益，需要还原为滚动 12 个月：

$$EPS_{TTM} = EPS_{\text{本期累计}} + EPS_{\text{上年年报}} - EPS_{\text{上年同期累计}}$$

- 四季报（年报）直接取累计值；
- 缺少上年数据时退化为 `本期累计 × 4 / 季度序号` 的简单年化；
- 港股接口直接提供 `EPS_TTM`，此时**跳过还原、直接采用**。

### 2.3 时点对齐（避免未来函数）

某个交易日只能使用**在该日之前已经公告**的报告：

```
游标沿「公告日升序」的财报时间线前移，
条件：timeline[i].VisibleFrom <= bar.Date
```

- A 股使用接口返回的 `NOTICE_DATE`；
- 港股接口不提供公告日，按**报告期 + 60 天**保守估计；
- 完全缺失时按报告期 + 45 天估计；
- 首份报告公告之前的交易日，PE / PB 为空（不参与统计）。

同一报告期若被多次修正，保留**公告日最早**的一条，同样是为了不引入未来信息。

### 2.4 与实时快照的口径校准

自算结果与交易所/行情商的口径存在系统性偏差，主要来自两点：

1. **币种**：港股报表常以人民币列示，而股价以港元报价；
2. **分子定义**：A 股「基本每股收益」与「归母净利润 ÷ 总股本」略有差异。

因此在序列构建完成后，用最新快照做一次**常数因子校准**：

$$k_{PE} = \frac{PE_{\text{自算,最新}}}{PE_{\text{快照}}}, \quad EPS'(t) = EPS(t)\cdot k_{PE},\quad PE'(t) = \frac{PE(t)}{k_{PE}}$$

PB 同理。要点：

- 这是**单调常数缩放**，因此**历史分位数完全不受影响**；
- 估值通道的价格带同样不变（`quantile(PE)·EPS(t)` 中的 `k` 相互抵消）；
- 唯一的效果是把「当前 PE / PB」对齐到用户在行情软件里看到的数值，避免困惑；
- 因子超出 `(0.2, 5)` 时视为数据异常，不做校准。

校准后的实测结果（2026-08-21）：

| 标的 | 自算 PE | 快照 PE | 自算 PB | 快照 PB |
|------|--------|---------|--------|---------|
| 贵州茅台 600519 | 19.54 | 19.54 | 6.33 | 6.33 |
| 工商银行 601398 | 7.46 | 7.46 | 0.71 | 0.71 |
| 腾讯控股 00700 | 15.59 | 15.59 | 3.18 | 3.18 |

### 2.5 降级：近似模式

当**完全取不到财报**时（例如极冷门标的），序列会退化为
`ValuationSeriesQuality.ApproximatedFromLatestQuote`：

- 用最新快照反推每股指标：`EPS = 价格 ÷ PE`、`BPS = 价格 ÷ PB`；
- 假设它们在整个窗口内恒定，于是 PE/PB 曲线形状与股价完全一致。

此模式**只能反映价格相对位置，不反映真实估值变化**，界面会在详情页明确提示。

## 3. 历史分位数

### 3.1 样本选取

- 窗口为 `[最新交易日 - N 年, 最新交易日]`，N ∈ {1, 3, 5, 10}；
- 剔除空值、`NaN`、`Infinity` 以及**非正值**（亏损期的负 PE 无经济含义）；
- 样本量与覆盖度都会展示：若窗口内最早样本比窗口起点晚 30 天以上，
  标记为「数据不足」（次新股常见）。

### 3.2 百分位口径

采用「小于等于计数法」，与东财、理杏仁等平台一致：

$$\text{Percentile} = \frac{\#\{x_i \le x_{\text{当前}}\}}{n}\times 100\%$$

### 3.3 分位点数值

采用**线性插值**（等价于 Excel `PERCENTILE.INC`、numpy 默认 `linear`）：

$$pos = q\,(n-1),\quad Q(q) = x_{\lfloor pos \rfloor}(1-w) + x_{\lceil pos \rceil}\,w,\quad w = pos - \lfloor pos \rfloor$$

界面展示 10%、20%、30%、50%、70%、80%、90% 七个分位点。

### 3.4 估值温度

| 百分位 | 评价 |
|--------|------|
| < 10% | 极度低估 |
| 10% ~ 30% | 低估 |
| 30% ~ 70% | 合理 |
| 70% ~ 90% | 高估 |
| ≥ 90% | 极度高估 |

**这只是历史统计位置的机械描述**，不含任何基本面判断。

## 4. 估值通道

对标东方财富 App 的「估值通道」：把估值倍数的分位数**折算回价格坐标**，
使「贵/便宜」可以直接与 K 线对比。

对窗口内的分位 `q ∈ {10%, 30%, 50%, 70%, 90%}`：

$$M_q = Q_q\big(\{PE_{TTM}(t)\}\big), \qquad \text{BandPrice}_q(t) = M_q \cdot EPS_{TTM}(t)$$

PB 通道同理，锚定值换成 `BPS(t)`。

解读：

- 股价贴近**下沿**：当前估值处于历史低分位；
- 股价贴近**上沿**：处于历史高分位；
- 通道整体**上移**：说明每股盈利/净资产在增长（业绩驱动）；
- 通道整体**下移**：盈利在下滑，此时即使股价不动，估值也在被动抬升。

图表同时给出「当前位置百分比」，与历史分位表中的同窗口数值一致。

## 5. 已知局限

| 局限 | 说明 | 影响 |
|------|------|------|
| 亏损股无 PE | 负 EPS 被剔除 | 周期股底部区间样本量骤减，PE 分位参考价值低，建议改看 PB |
| 累计口径还原 | 用「本期 + 上年年报 − 上年同期」还原 TTM | 遇到重大重组、会计政策变更或追溯调整时会有偏差 |
| 股本变动 | 使用每股指标可自动吸收大部分股本变化 | 但重大再融资 / 分拆前后的可比性仍会打折 |
| 港股公告日 | 接口未提供，按报告期 + 60 天估计 | 财报切换点的日期可能有几周误差 |
| 交易日历 | 未内置节假日表，只跳过周末 | 仅影响缓存新鲜度判断，不影响计算结果 |
| 汇率 | 用单一常数因子校准，未使用逐日汇率 | 港股历史 PE 的绝对水平会有轻微偏移；**分位数与通道形状不受影响** |
| 分红除权 | 使用不复权价，未做股息再投资调整 | 与主流估值平台口径一致 |
